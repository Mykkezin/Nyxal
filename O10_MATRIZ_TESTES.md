# O10 — Matriz de Testes

## Entrada

1. Evidência válida é aceita.
2. Entrada não pertencente ao contrato é rejeitada.

## Identidade

3. Identidade correta é aceita.
4. Identidade alterada é rejeitada.

## Cardinalidade

5. Total de relações correto é aceito.
6. Total de relações incorreto é rejeitado.
7. Total de nós correto é aceito.
8. Total de nós incorreto é rejeitado.
9. Total de ciclos correto é aceito.
10. Total de ciclos incorreto é rejeitado.

## Relações

11. Relações rastreáveis são aceitas.
12. Relação ausente da estrutura é rejeitada.
13. Duplicatas legítimas continuam válidas.
14. Nenhuma relação nova é criada.

## Autoridade

15. Distribuição observacional correta é aceita.
16. Distribuição experimental correta é aceita.
17. Distribuição alterada é rejeitada.
18. Autoridade arquitetural não pode surgir.

## Tipos

19. Distribuição correta de tipos é aceita.
20. Distribuição alterada é rejeitada.

## Ciclos

21. Distribuição correta de ciclos é aceita.
22. Distribuição alterada é rejeitada.

## Pares

23. Distribuição correta de pares é aceita.
24. Distribuição alterada é rejeitada.

## Epistemologia

25. Qualificação não cria causalidade.
26. Qualificação não cria aprendizado.
27. Qualificação não cria autoridade arquitetural.

## Imutabilidade

28. Evidência original permanece imutável.
29. Resultado da qualificação é imutável.

## Isolamento

30. O módulo não acessa planta, Runtime ou filesystem.
